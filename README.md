# 📚 TeluLex

**TeluLex** is a modern personal English ↔ Telugu dictionary built with **Streamlit** and **SQLite**. It helps you build your vocabulary by saving, searching, updating, and deleting words while tracking your daily learning progress through an interactive dashboard.

---

## ✨ Features

### 📖 Dictionary Management
- ➕ Add new English–Telugu words
- 🔍 Instant search in English or Telugu
- 📝 Edit and update existing words
- 🗑️ Delete saved words
- 💬 Save example sentences
- 📊 Live total words counter

### 📈 Dashboard
- 📅 Date-wise learning history
- 🔥 Daily learning streak tracker
- 📊 Number of words added each day
- 📋 Activity table grouped by date
- 📈 Dictionary growth overview

### 🎨 User Interface
- 📱 Clean and responsive interface
- ⚡ Fast Streamlit application
- 🖼️ Custom navigation banner
- 📑 Organized sections for Add, Edit and Delete

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/TeluLex.git
```

### Navigate to the project

```bash
cd TeluLex
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
streamlit run app.py
```
